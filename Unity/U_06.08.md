### 변수 선언하기
상자에 어떤 종류의 데이터를 넣을지, 상자 이름으로 무엇을 쓸지 **선언**해야 합니다.
int - 정수형
float - 부동소수점형
double - 배정도부동소수점형
bool - 불형
char - 문자형
string - 문장열형

- 변수 선언 방법
	- 데이터형 이름 변수명;
    	> int a;

- 변수에 값을 대입하는 방법
    - 변수명 = 대입할 값;
        > a = 30;

- 변수를 초기화하는 방법
    - 데이터형 이름 변수명 = 대입할 값;
        > int a = 30;

- 변수에 변수를 대입하는 방법
    - 변수명 = 대입할 변수명;
        > a = b;

- 변수에 문자열을 대입하는 방법
    - 변수명 = "대입할 문자열";
        >string name;\
    name = "Sera";\
    Debug.Log(name);

- 변수에 계산 결과를 대입하는 방법
    - 변수명 = 숫자 + 숫자;
        > a = 10 + 20;
    - 변수 값을 일정하게 늘리고 싶을 때
        > a += 5; \
        (a = a + 5)
    - 변수 값을 1만큼 늘릴 때
        > a++; \
        (a = a + 1)
    - 변수 값을 1만큼 감소 시킬 때
         > a--;\
         (a = a - 1)

- 문자열과 문자열의 연결
    - + 연산자나 += 연산자를 사용해 문자열을 연결할 수 있습니다.
        > string str1 = "Happy "; \
        string str2 = "birthday"; \
        string message;\
        message = str1 + str2;
        (str1 += str2)

### 제어문 사용하기
- if 문으로 조건 분기하기
    > if(조건식)\
    {\
    }

- if~eles 문으로 조건 분기하기
    - 조건식을 만족할 때와 만족하지 않을 때를 각각 다르게 처리할 때
        >if (조건식) {처리 A}\
        else {처리 B}

- if 문 추가하기
    - 조건이 두 개 이상이면
        >if(조건식 a) {처리 A}\
        else if (조건식 b) {처리 B}\
        else if (조건식 c) {처리 C}\
        else {처리 D}

- 변수 범위
    - if 문의 블록에서 정의한 변수는 사용할 수 있는 범위가 정해져 있습니다.

- for 문으로 반복하기
    - 반복 횟수를 지정하면 자동으로 반복 횟수만큼 처리를 반복하는 **for 문**을 사용합니다.
        > 잘못된 사용 방법\
        for (반복 횟수)\
        {\
        }
    - for (변수 초기화; 반복 조건식; 변수 갱신)
