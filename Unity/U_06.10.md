# Unity 06.10
## 메서드 만들기
> 모아 둔 처리마다 이름을 붙여 각각을 블록으로 사용할 수 있는ㄷ 메서드를 쓰면 편리합니다.

### 2.7.1 메서드
**의미가 있는 처리 블록으로 분해하고 이름을 붙이는** 구조를 만드는데, 이렇게 분해한 각 처리를 **메서드**(또는 함수)라고 합니다.

메서드는 처리를 기능 단위로 묶는 역할 외에도 메서드에 값을 전달해서 계산하거나 계산 결과를 돌려받을 수 있도록 하는 역할\
**메서드로 건네는 값을 *인수*, 메서드에서 돌려받는 값을 *반환값* .**이라고 합니다.\
**인수는 여러 개 건넬 수 있지만 반환값은 한개로 정해져 있습니다.**

### 2.7.2 메서드를 만드는 방법
*반환값의 데이터형* **에는 호출자의 메서드로 반환하는 값의 데이터 형을 지정합니다**\
지정할 데이터형은 변수의 데이터형과 같다. 값을 반환하지 않는 메서드는 **void**를 지정합니다.

- void란, '반환값이 없음'을 의미한다
- **인수**는 호출자의 메서드에서 받은 값입니다.

**메서드는 인수 값을 사용해서 처리를 실행합니다.** 인수를 갖지 않는 메서드도 있는데 이때는 메서드명 뒤에 붙는 괄호 안을 공백으로 비웁니다.

### 2.7.3 인수도 반환값도 없는 메서드
> 반환값의 데이터형에 void를 지정합니다. 인수가 없으므로 메서드명 뒤에 붙는 괄호 안을 공백으로 비웁니다.

#### 메서드 호출 방법
>작성한 메서드는 호출에서 사용한다는 것

함수명(); -  함수명을 작성하고 메서드를 호출한다

### 2.7.4 인수가 있는 메서드
#### 메서드 작성 방법 
문자열을 인수로 받으므로 메서드명에 이어 괄호 안에 string형의 name 변수를 선언 합니다.
> void CallName(string name)

#### 메서드 호출 방법
CallName 메서드 안에 ("Hello" + name)이라 적고

CallName("Tom");이라고 적으면\
CallName 메서드를 호출하면 인수의 문자열인 "Tom"이 자동으로 메서드 안의 name 변수에 대입됩니다. name 메서드는 메서드에서 변수처럼 쓸 수 있으므로 name 변수 값을 출력합니다.

### 2.7.5 인수와 반환값이 있는 메서드
#### 메서드 작성 방법
> int Add(int a, int b)

반환값을 돌려주려면 return문 뒈어 공백을 두고 변수명을 적으면 그 변수 값을 메서드를 호출한 곳으로 반환할 수 있습니다.
#### 메서드 호출 방법
> Add(2, 3)

메서드를 호출하는 쪽에서는 메서드명에 이어 인수를 두 개(2와 3) 전달합니다. 메서드 호출과 동시에 a와 b 변수에는 각각 2와 3이 대입됩니다. **a와 b 변수에는 메서드를 호출하는 곳에서 지정한 순서대로 값이 대입됩니다.** \
**메서드를 실행한 후에는 메서드의 호출 부분이 반환값으로 바뀌는 형태입니다.**
