### OnCollisionEnter2D
```csharp
private void OnCollisionEnter2D(Collision2D collision)
    {
        ContactPoint2D contact = collision.GetContact(0);
        print($"collision : {contact.normal}");
    }
```
#### OnCollisionEnter2D 정리
충돌받은 방향

ContactPoint = 접촉 지점

GetContact = 충돌 대상에 정보를 가져온다.  \
print(contact.normal) = 충돌체가 상하좌우 어디에 부딧혔는지 \
(상(0, -1),하(0, 1),좌(1, 0),우(-1, 0))

### Raycast

```cs
private void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            int layerMask = ~LayerMask.GetMask("Player");
            RaycastHit2D hit2d = Physics2D.Raycast(transform.position, Vector2.down, 3.0f, layerMask);
            
            print($"raycast : {hit2d.normal}");
        }
    }
```
#### Raycast 정리

선을 쏘고 닿은 방향

회전이 없다면, 충돌한 면((1,0), (-1,0) 옆면,(0, 1), (0, -1) 상/하) 절대 값으로 |값|을 넣어 정수로 변환\
회전이 있다면, 내적을 사용하여 각도를 찾고 각도 사이에 근삿값으로 충돌면을 검출함.
