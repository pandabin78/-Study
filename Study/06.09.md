1. 일반적 이미지와 스프라이트 이미지는 다르다.
2. 스프라이트는 부드럽게 나오지 않는다
3. 다만 부드럽게 나온다면 filter mode가 biliner linear로 되어있어서 그렇다
4. filter Mode를 사용하지 않는 경우 Point(점)


- 이미지를 보여주기 전에 보간(Interpolation)
>Interpolation중 가장 쉬운게 Linear Interpolation(Lerp선형 보간)\
(1-t) * A + t * B\
0 = A\
1 = B\
0.5 = 0.5, 0, 0.25\
0.25 = A0.75 + B0.25
