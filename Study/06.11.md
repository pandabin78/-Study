### Unity monobehaviour lifecycle
- private void Awake()
    > 컴퍼넌트, 초기화
- private void Start()
    > 값을 작성 start 부터 시작, 첫번째 업데이트 직전(게임 로직)
- private void OnEnable()
    > Awake다음 호출 이밴트가 실행될때 재실행시 start를 넘김, Start() 직전에 호출, 객체를 다시 활성화해도 호출
- private void OnDisable()
    > 호출 이밴트가 끝날 때, 객체 비활성화, 게임 오브젝트가 제거될때도 호출\
    Destroy로 객체 삭제나 게임 종료시 제거됨
- private void Update()
