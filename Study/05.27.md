프로그래밍(is a, has a, as)  is(캐스팅이 가능한지 판단 가능하면true 불가능 false, 상속구조) as(변환해서 값을 돌려주는 것)
- A is a B
    > class A {int c;} class B:A {int d;} \
    B ob = new B(); \
    A oba = ob as A; oba는 A영역만 가짐 c공간 사용 가능, d공간은 사용 불가\
    ob라는 공간안에 자기에 변수 d가 들어감 하지만 B는 A에 상속을 받아 상속받은 A공간안에 c공간이 생김.\
    부모에서 자식으로 올라가는 것을 업캐스팅, 자식이 부모 공간을 가지고 있으면 캐스팅이 가능하다.

class C : A {int e;}
C obc = new C();
A obd = obc as A;
B obe = obd as B; // 부모에서 자식으로 내려가는 것을 다운 캐스팅
