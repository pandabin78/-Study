# 02-1 0과 1로 숫자를 표현하는 방법
## 삼육진법
이진법은 0과 1만으로 모든 숫자를 표현하다 보니 숫자의 길이가 너무 길어진다는 단점이 있습니다.\
십진수 32를 이진수로 표현하면 1000000(2)과 같이 여섯 개의 자릿수가 필요한 것처럼요.\

그래서 데이터를 표현할 때 이진법 이외에 십육진법도 자주 사용합니다.\
**십육진법**은 수가 15를 넘어가는 시점에서 자리 올림을 하는 숫자 표현 방식입니다.\
그리고 십진수 10,11,12,13,14,15를 십육진법 체계에서는 각각 A,B,C,D,E,F로 표기합니다.

> **십육진법**은 15를 넘어가는 시점에 자리 올림하여 수를 표현하는 방법입니다.

## 십육진수를 이진수로 반환하기
십육진수는 한 글자당 열여섯 종류(0~9, A~F)의 숫자를 표현할 수 있다\
그렇다면 16진수를 이루는 숫자 하나를 이진수로 표현하려면 4비트다 2에4제곱  = 16이기 때문

16진수를 2진수로 변환하는 간편한 방법 중 하나는 16진수 한 글자를 4비트의 이진수로 간주 하는 것\
즉, 16진수를 이루고 있는 각 글자를 따로따로 (4개의 숫자로 구성된) 2진수로 변환하고,\
그것들을 그대로 이어 붙이면 16진수가 2진수로 변환된다.

예를 들어 1A2B(16)라는 16진수가 있을 때 각 숫자 1(16), A(16), 2(16), B(16)를 이진수로 표현하면 0001(2), 1010(2), 0010(2), 1011(2)다\
즉 0001101000101011(2)이 1A2B(16)를 이진수로 표현한 값

## 2진수를 16진수로 표현하기
반대로 2진수를 16진수로 변환할 때는 이진수 숫자를 네 개씩 끊어 준 네 개의 숫자를 하나의 16진수로 변환한 뒤 그대로 이어 붙이면 됩니다.\
예를 들어 11010101(2)이라는 2진수를 네 개씩 끊으면 1101(2), 0101(2),이고 이는 각각 D(16)와 5(16)이므로 이를 그대로 이어 붙이 D5(16)가 11010101(2)를 16진수로 변환한 수 입니다

### 여기서 잠깐 - 코드에 16진수를 직접 넣는 사례
16진수는 프로그래밍할 때 2진수와 더불어 자주 사용되므로 기억해 두는 것이 좋습니다.\
하드웨어와 밀접하게 맞닿아 있는 개발 분야에서는 아래와 같이 코드에 16진수를 직접 쓰는 경우도 더러 있기 때문입니다.

```
offset = _mem_to_opcode_arm(*(u32 *)loc);
offset = (offset & 0x00ffffff) << 2;
if(offset & 0x02000000)
offset -= 0x04000000;
offset += sym->st_value - loc;
```

위 코드가 무슨 뜻인지 알 필요는 없습니다. 프로그래밍할 때 16진수를 직접 서넣는 경우도 많다는 사실만 인지하면 됩니다.

### 5가지 키워드로 정리하는 핵심 포인트
- **비트**는 0과 1로 표현할 수 있는 가장 작은 정보 단위입니다.
- **바이트**, 킬로바이트, 메가바이트, 테라바이트는 비트보다 더 큰 정보 단위입니다.
- **2진법**은 1을 넘어가는 시점에 자리 올림을 하여 0과 1만으로 수를 표현하는 방법
- 2진법에서 음수는 **2의 보수**로 표현할 수 있습니다.
- 16진법은 15를 넘어가는 시점에 자리 올림하여 수를 표현하는 방법
