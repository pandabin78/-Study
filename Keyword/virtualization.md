# 가상화
>가상화(Virtualization)란 물리적인 컴퓨터 리소스(CPU, 메모리, 저장장치 등)를 추상화하여, 하나의 물리적 자원을 여러 개의 가상 자원으로 나누거나 반대로 여러 개의 자원을 하나로 통합하여 사용할 수 있게 하는 기술입니다.\
쉽게 말해, 한 대의 컴퓨터(서버) 안에 여러 대의 가상 컴퓨터(가상 머신, VM)를 만들어 각각 서로 다른 운영체제(OS)와 프로그램을 독립적으로 실행하는 기술을 의미합니다. 
### 💡 실생활 예시
 - 아파트 모델 하우스(가상화)
     >커다란 건물 한 층(물리 서버) 안에 벽을 세워 24평형, 34평형 공간(가상 머신)을 독립적으로 분할합니다. 각 공간은 독립된 집처럼 보이지만, 실제로는 하나의 큰 공간을 나누어 쓰고 있는 것입니다.
### ⚙️ 가상화의 핵심 구성 요소 
- 호스트(Host)
    >실제 눈에 보이는 물리적인 컴퓨터(하드웨어)입니다.
- 하이퍼바이저(Hypervisor)
    >물리 하드웨어와 가상 머신 사이를 중재하는 소프트웨어입니다. 리소스를 분배하고 가상 머신을 제어하는 핵심 역할을 합니다. (예: VMware, VirtualBox, Hyper-V)
- 게스트(Guest / VM)
    >하이퍼바이저 위에서 독립적으로 작동하는 가상 컴퓨터와 그 안의 운영체제(OS)입니다. 
### 🛠️ 가상화의 방식 분류
1. 독자 실행형 (Type 1, Bare-Metal) 
    - 특징
        >하드웨어 바로 위에 하하이퍼바이저가 설치되는 방식입니다.
    - 장점
        >중간 OS가 없어 호스트 OS형보다 속도가 빠르고 리소스 관리가 효율적입니다. 기업형 서버에 주로 쓰입니다.
    - 예시
        >VMware ESXi, Citrix XenServer, KVM 
2. 호스트 실행형 (Type 2, Hosted)
    - 특징
        >기존에 쓰던 OS(Windows, macOS 등) 위에 하이퍼바이저 프로그램을 설치하는 방식입니다.
    - 장점
        >일반 사용자가 접근하기 쉽고 설치가 간편하지만, 호스트 OS를 거치기 때문에 성능 오버헤드가 발생합니다.
    - 예시
        >Oracle VirtualBox, VMware Workstation 
### 🚀 가상화를 사용하는 이유 (장점)
- 비용 절감
    >서버 10대가 필요할 때 물리 서버 10대를 사는 대신, 고성능 서버 1대를 사서 가상 머신 10개를 띄우면 되므로 장비 구입비와 전기세가 줄어듭니다.
- 자원 효율성 극대화
    >평소 사용률이 10% 미만인 서버들을 하나로 통합하여 하드웨어 자원을 놀리지 않고 100% 가깝게 활용합니다.
- 유연한 환경 격리
    >하나의 가상 머신에 악성코드가 감염되거나 OS가 다운되어도, 다른 가상 머신이나 실제 호스트 컴퓨터에는 아무런 영향을 주지 않습니다.
