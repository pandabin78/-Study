# 메모리 인터리빙
> 메모리 인터리빙(Memory Interleaving)은 인접한 메모리 주소를 여러 개의 독립된 메모리 모듈(뱅크)에 번갈아가며 배치하여, **CPU가 여러 모듈에 동시 또는 동시성에 준하게 접근할 수 있도록 하는 속도 향상 기법**입니다.\
메모리 인터리빙의 목적은 CPU의 빠른 처리 속도와 주기억장치(RAM)의 상대적으로 느린 접근 속도 사이의 병목 현상을 줄이는 것입니다.

### ?? 핵심 원리: 병렬 접근
> 메모리는 한 번 데이터를 읽고 나면 다시 읽기 전까지 최소한의 재충전/준비 시간(Memory Cycle Time)이 필요합니다.\
인터리빙은 이 제약을 하드웨어적으로 우회합니다.

- 하나의 메모리 칩에서 데이터를 연속으로 가져오면 대기 시간이 발생합니다.
- 하지만 데이터를 **모듈 0, 모듈 1, 모듈 2, 모듈 3** 순서로 분산해 두면, CPU는 모듈 0의 대기 시간동안 모듈 1, 2, 3에서 데이터를 연속으로 가져올 수 있습니다.
- 결과적으로 **메모리 버스의 대역폭이 확장**되고 데이터 전송 속도가 비약적으로 상승합니다

### ?? 메모리 인터리빙의 종류
- 상위 인터리빙(High-Order Interleaving)
    - 주소의 상위 비트를 사용하여 메모리 모듈을 선택합니다.
    - 하나의 모듈 내에 연속된 주소가 차례대로 저장되는 방식입니다.
    - 독자적인 프로그램 수행에는 유리하지만, 연속적인 데이터 접근 시 병렬 처리 효과가 떨어집니다. (주로 모듈 확장이나 장애 격리에 유리)

- 하위 인터리빙(Low-Order Interleaving)
    - 주소의 하위 비트를 사용하여 메모리 모듈을 선택합니다.
    - 연속된 주소의 데이터들이 **모듈마다 번갈아가며(순환식으로)저장**됩니다.
    - CPU가 연속된 메모리 공간(예 : 배열, 명령어 인출)을 읽을 때 여러 모듈을 동시에 가동하므로 **실질적인 인터리빙 성능 향상**을 이끌어냅니다.\
      일반적으로 인터리빙이라고 하면 이를 뜻합니다.

### ?? 실생활에서의 예시: 듀얼 채널(Dual Channel)
> 우리가 PC를 조립할 때 RAM을 1개만 꽂지 않고, 8GB짜리 2개를 **1번, 3번 슬롯에 나누어 꽂아 '듀얼 채널'을 구성**하는 것이 하드웨어 레벨에서 메모리 인터리빙을 활성화하는 가장 대표적인 예시입니다.
