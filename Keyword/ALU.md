# ALU
>ALU(산술 논리 장치, Arithmetic Logic Unit)는 컴퓨터의 두뇌인 중앙처리장치(CPU)의 핵심 구성 요소로, 모든 산술 연산과 논리 연산을 실제로 처리하는 디지털 회로입니다. 
1. 주요 기능
    >ALU는 제어 장치(Control Unit)의 지시에 따라 두 가지 유형의 연산을 수행합니다. 

- 산술 연산(Arithmetic Operations)
    >덧셈(), 뺄셈(), 곱셈(), 나눗셈() 등 기본적인 수학 계산을 수행합니다.
- 논리 연산(Logic Operations)
    >AND, OR, NOT, XOR 등 참과 거짓을 판별하는 연산과 두 수의 크기를 비교하는 작업을 수행합니다. 

2. 내부 핵심 구성 요소
    >ALU가 연산을 안정적으로 처리하기 위해 내부적으로 다음과 같은 회로와 레지스터를 사용합니다. 
    - 가산기(Adder)
        >두 수를 더하여 합을 구하는 기초적인 연산 회로입니다.
    - 보수기(Complementer)
        >뺄셈을 수행하기 위해 숫자를 음수(보수) 형태로 변환하는 회로입니다.
    - 누산기(Accumulator, AC)
        >연산 결과를 일시적으로 저장하는 핵심 레지스터입니다.
    - 데이터 레지스터(Data Register)
        >연산할 데이터를 임시 보관하는 장치입니다.
    - 플래그 레지스터(Status/Flag Register)
        >연산 결과가 양수인지, 음수인지, 혹은 오버플로우(자릿수 넘침)가 발생했는지 등의 상태 정보를 저장합니다. 

3. 작동 원리
- 데이터 입력
    >연산할 데이터(피연산자)가 레지스터를 통해 ALU로 들어옵니다.
- 제어 신호 수신 
    >CPU의 제어 장치(Control Unit)가 ALU에게 "어떤 연산(예: 덧셈)을 하라"는 제어 신호를 보냅니다.
- 연산 및 출력
    >ALU는 지정된 연산을 수행한 뒤, 결과값과 결과의 상태(플래그)를 각각 레지스터로 내보냅니다.
