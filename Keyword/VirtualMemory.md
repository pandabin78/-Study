# 가상메모리
>가상 메모리(Virtual Memory)는 물리적 메모리(RAM)의 한계를 극복하기 위해 보조기억장치(HDD/SSD)의 일부를 주기억장치처럼 사용하는 메모리 관리 기법입니다. 이를 통해 CPU는 실제 설치된 RAM 용량보다 더 큰 프로그램이나 여러 프로그램을 동시에 실행할 수 있습니다.

### ?? 가상 메모리의 핵심 목적
- 용량 제한 극복: 
	>16GB RAM 환경에서도 32GB 용량의 대형 프로그램을 실행할 수 있습니다.
- 메모리 보호: 
    >각 프로세스에 독립적인 가상 주소 공간을 부여하여, 한 프로그램이 다른 프로그램의 메모리 영역을 침범하지 못하게 차단합니다.

### ?? 가상 메모리 관리 기법 (Mapping)
>가상 주소(Virtual Address)를 실제 물리 주소(Physical Address)로 변환하기 위해 MMU(Memory Management Unit)라는 하드웨어 장치를 사용하며, 크게 두 가지 방식으로 나뉩니다.

1. 페이징 (Paging):
    - 가상 메모리와 물리 메모리를 고정된 크기의 블록으로 나누어 관리합니다.
    - 가상 메모리의 블록을 페이지(Page), 물리 메모리의 블록을 프레임(Frame)이라고 합니다.
    - 내부 단편화(Internal Fragmentation)가 발생할 수 있습니다.
2. 세그먼테이션 (Segmentation):
    - 프로그램을 논리적 단위(코드, 데이터, 스택 등)인 가변적인 크기의 블록으로 나눕니다.
    - 크기가 다르므로 외부 단편화(External Fragmentation)가 발생할 수 있습니다.

### ?? 페이지 교체 알고리즘 (Page Replacement)필요한 페이지가 물리 메모리에 없을 때(페이지 부재, Page Fault), 보조기억장치에서 페이지를 가져와야 합니다. 만약 RAM이 가득 찼다면 기존 페이지 중 하나를 내보내야 하는데, 이때 사용되는 알고리즘입니다.
- FIFO (First-In, First-Out): 
    > 메모리에 가장 먼저 들어온 페이지를 먼저 교체합니다.
- LRU (Least Recently Used): 
    > 가장 오랫동안 사용되지 않은 페이지를 교체합니다. (가장 대중적)
- LFU (Least Frequently Used): 
    > 참조 횟수가 가장 적은 페이지를 교체합니다.

### ?? 주의해야 할 현상: 스래싱 (Thrashing)
- 정의: 프로세스가 수행하는 시간보다 페이지를 교체하는(디스크 입출력) 시간이 더 많아져 CPU 효율이 급격히 떨어지는 현상입니다.
- 원인: 실행 중인 프로그램들에 비해 물리 메모리(RAM) 용량이 너무 부족할 때 발생합니다.
- 해결책: RAM을 추가하거나, 워킹 세트(Working Set) 알고리즘 등을 통해 프로세스당 적절한 프레임을 할당해야 합니다.
