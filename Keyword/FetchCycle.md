# 인출 사이클
>인출 사이클(Fetch Cycle)은 CPU가 메모리에 저장된 다음 명령어(기계어)를 CPU 내부로 읽어오는 과정을 말합니다. \
이 과정은 CPU가 프로그램을 실행할 때 반복적으로 수행되는 '명령어 사이클(Instruction Cycle)'의 첫 번째 단계입니다. 
- 주소 전송: 
    >CPU의 프로그램 카운터(PC)에 저장된 명령어 주소를 메모리 주소 레지스터(MAR)로 보냅니다.
- 명령어 읽기: 
    >메모리에서 해당 주소의 명령어를 읽어 메모리 버퍼 레지스터(MBR)에 저장하고, 다음 명령어를 읽기 위해 PC의 값을 1 증가시킵니다.
- 명령어 저장: 
    >MBR에 있는 명령어를 명령어 레지스터(IR)로 가져옵니다.
- 해석 준비: 
    >IR로 가져온 명령어를 CPU의 제어장치가 해독하여 어떤 동작을 해야 할지 판단할 준비를 마칩니다
