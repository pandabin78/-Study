# SLDC
>SDLC(소프트웨어 생명 주기, Software Development Life Cycle)는 소프트웨어를 기획하고 개발하여 폐기하기까지의 전체 과정을 단계별로 나누어 체계화한 프로세스 모델입니다.\
1968년 소프트웨어 위기를 극복하기 위해 도입되었으며, 고품질의 소프트웨어를 최소한의 비용과 최단 기간에 개발하는 것을 목표로 합니다.
### 🔄 SDLC의 핵심 5단계
- 요구사항 분석 (Analysis)
    >고객의 요구 사항을 수집하고 비즈니스 목표를 정의하여 문서화하는 가장 중요한 단계입니다.
- 시스템 설계 (Design)
    >아키텍처, 데이터베이스, UI/UX 등 소프트웨어의 구조와 사양을 구체적으로 기획합니다.
- 구현 및 개발 (Implementation)
    >설계서를 바탕으로 개발자가 실제 소스 코드를 작성하고 프로그램을 만드는 단계입니다.
- 테스트 (Testing)
    >완성된 소프트웨어의 버그를 찾아내고, 초기 요구사항대로 잘 작동하는지 품질을 검증합니다.
- 유지보수 (Maintenance)
    >배포 후 발생하는 오류를 수정하고, 사용자의 피드백을 반영해 기능을 개선하는 지속적인 과정입니다.
### 🗺️ 대표적인 SDLC 모델 종류
- 폭포수 모델 (Waterfall)
    >각 단계를 순차적으로 완벽히 끝내고 다음 단계로 넘어가는 전통적인 모델로, 요구사항 변경이 적은 프로젝트에 적합합니다.
- 프로토타입 모델 (Prototype)
    >시제품(Prototype)을 빠르게 만들어 고객의 피드백을 받아가며 요구사항을 조율하는 방식입니다.
- 나선형 모델 (Spiral)
    >계획, 위험 분석, 개발, 평가 단계를 반복하며 위험 요소를 최소화하는 대규모 대형 프로젝트용 모델입니다.
- 애자일 모델 (Agile)
    >일정한 주기를 가지고 끊임없이 프로토타입을 만들어 배포하는 현대적인 방식으로, 변화에 유연하고 신속하게 대응합니다.
