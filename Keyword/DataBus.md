# Data Bus
>데이터 버스(Data Bus)는 CPU, 메모리, 주변 장치 간에 실제 데이터와 명령어를 서로 주고받는 양방향 통신 통로입니다. \
질문하신 'Data Bud'는 'Data Bus'의 오타로 보이며, 앞서 살펴본 주소 버스와 함께 컴퓨터 핵심 통신망을 이룹니다.
### ⚙️ 1. 주요 특징과 작동 원리
- 양방향 통신
    >주소 버스와 달리 신호가 양방향으로 흐릅니다. CPU가 메모리에서 데이터를 읽어올 수도 있고(Read), 반대로 메모리에 데이터를 저장할 수도(Write) 있기 때문입니다.
- 도로의 폭과 성능
    >데이터 버스의 선(Line) 개수는 한 번에 전송할 수 있는 데이터의 양을 결정합니다. 이를 버스 폭(Bus Width)이라고 합니다.
### ⚡ 2. 32비트와 64비트 컴퓨터의 진짜 차이
>우리가 흔히 말하는 '64비트 컴퓨터'나 '64비트 프로세서'는 바로 이 데이터 버스의 폭과 CPU 내부 레지스터의 크기를 의미합니다.
- 32비트 데이터 버스
    >한 번에 32비트(4바이트)의 데이터만 나를 수 있습니다.
- 64비트 데이터 버스
    >한 번에 64비트(8바이트)의 데이터를 처리합니다. 32비트 컴퓨터보다 동시에 2배 많은 데이터를 전송하므로 연산 속도가 압도적으로 빠릅니다.
### 🚌 3. 주소 버스(Address Bus)와의 연계 과정
>CPU가 메모리에서 데이터를 읽어올 때 두 버스는 다음과 같이 움직입니다.
1. 주소 버스
    >CPU가 "10번지 데이터를 가져와라"며 주소 버스에 10을 싣고 보냅니다.
2. 제어 버스
    >CPU가 제어 버스를 통해 "읽기(Read)" 신호를 보냅니다.
3. 디코더
    >메모리 장치의 디코더가 주소 버스의 신호를 해독해 10번지 방을 엽니다.
4. 데이터 버스
    >10번지 방에 있던 데이터가 데이터 버스를 타고 CPU로 이동합니다.
