# Control Bus
>**제어 버스(Control Bus)**는 CPU가 메모리나 주변 장치에 "무엇을 해야 하는지" 제어 신호(명령 및 상태)를 전달하는 통신 통로입니다. \
주소 버스가 위치를 찾고 데이터 버스가 물건을 나른다면, 제어 버스는 전체 시스템의 작업 타이밍과 행동을 지시하는 제어 센터 역할을 합니다.
### ⚙️ 1. 주요 특징과 작동 원리
- 복합 방향성
    >전체적으로는 양방향에 가깝지만, 선(Line)마다 역할이 달라 단방향 선들의 집합으로 구성됩니다. CPU가 명령을 내리는 선도 있고, 반대로 주변 장치가 CPU에 상태를 보고하는 선도 있습니다.
- 시스템 동기화
    >컴퓨터 부품들이 서로 다른 속도로 작동할 때, 데이터가 꼬이지 않도록 타이밍 신호(클록 신호)를 주어 전체 시스템의 싱크를 맞춥니다. 
### 🔌 2. 제어 버스를 흐르는 핵심 신호들
>제어 버스는 하나의 통로처럼 보이지만, 실제로는 다음과 같은 독립된 제어선들의 묶음입니다.
- Memory Read / Write
    >메모리에서 데이터를 읽을지, 메모리에 데이터를 쓸지 결정하는 신호입니다.
- I/O Read / Write
    >키보드, 마우스, 모니터 같은 주변 장치와 데이터를 주고받을 때 사용합니다.
- Clock (클록)
    >각 장치 간의 작업 시간을 맞추기 위한 주기적인 메트로늄 신호입니다.
- Interrupt (인터럽트)
    >마우스 클릭이나 오류 발생 등 주변 장치가 CPU에 급한 일을 먼저 처리해 달라고 보내는 비상 신호입니다.
- Reset (리셋)
    >시스템 전체를 초기 상태로 되돌리는 신호입니다. 
### 🚌 3. 시스템 버스 3형제 최종 요약
>지금까지 살펴본 컴퓨터의 3대 버스는 하나의 데이터를 처리하기 위해 다음과 같이 완벽한 삼박자로 움직입니다.
- 주소 버스: "어디로 갈까?" (-> 메모리 주소 지정)
- 제어 버스: "무엇을 할까?" (-> 읽기 또는 쓰기 명령)
- 데이터 버스: "물건을 나르자!" (-> 실제 데이터 이동)
