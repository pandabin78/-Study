# 간접 사이클
>간접 사이클(Indirect Cycle)은 컴퓨터 구조에서 CPU가 명령어를 실행하기 전, 데이터의 실제 주소(유효 주소)를 기억장치(메모리)로부터 한 번 더 읽어0오는 과정을 뜻합니다.

### 핵심 요약
- 정의: 
    >명령어의 주소 필드가 데이터의 값이 아닌 '데이터가 저장된 실제 주소'를 가리키고 있을 때(간접 주소지정 방식) 발생합니다.
- 위치:
    >전체 명령어 사이클 중 인출 사이클(Fetch Cycle)과 실행 사이클(Execution Cycle) 사이에 실행됩니다.
- 조건:
    >모든 명령어에서 실행되지 않으며, 간접 주소지정 방식(Indirect Addressing Mode)을 사용하는 명령어일 때만 선택적으로 수행됩니다.

### 명령어 사이클 내에서의 위치
>컴퓨터의 기본 명령어 처리 주기인 명령어 사이클은 보통 아래와 같은 흐름으로 진행됩니다.
```
인출 사이클 (Fetch) ──> 간접 사이클 (Indirect) ──> 실행 사이클 (Execute) ──> 인터럽트 사이클 (Interrupt)
```
- 인출 사이클: 메모리에서 명령어를 가져와 CPU의 명령어 레지스터(IR)에 적재합니다.
- 간접 사이클: 가져온 명령어의 주소를 참조해, 실제 데이터가 들어있는 진짜 메모리 주소를 다시 읽어옵니다.
- 실행 사이클: 해독된 명령어와 유효 주소를 이용해 실제 연산을 수행합니다.

### 간접 사이클의 마이크로 연산 (Micro-operation)
>간접 사이클 동안 CPU 내부의 레지스터들은 다음과 같은 순서로 미세 동작을 수행합니다\

1.$$t_0 : \text{MAR} \leftarrow \text{IR(addr)}$$
>명령어 레지스터(IR)의 주소 필드 값을 메모리 주소 레지스터(MAR)로 보냅니다.

2.$$t_1 : \text{MBR} \leftarrow \text{M[MAR]}$$
>MAR이 가리키는 메모리 주소(M)에서 실제 데이터의 주소 값을 읽어와 메모리 버퍼 레지스터(MBR)에 저장합니다.

3.$$t_2 : \text{IR(addr)} \leftarrow \text{MBR}$$
>MBR에 저장된 실제 유효 주소를 다시 IR의 주소 필드에 덮어써서 실행 사이클로 넘겨줄 준비를 합니다.
