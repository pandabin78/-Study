# Decorder
>디코더(Decoder, 해독기)는 컴퓨터 회로에서 인코딩된(부호화된) 정보를 원래의 형태로 되돌리거나, 이진수 신호를 특정 신호로 변환하는 디지털 논리 회로입니다. \
앞서 설명해 드린 CPU 내부에서 제어 장치(Control Unit)가 명령어의 뜻을 분석할 때 핵심적으로 사용됩니다.
1. 주요 기능 및 특징
- 신호 변환: 
    n개의 입력 선으로 들어온 이진수 신호를 분석하여, 최대 n^2개의 출력 선 중 단 하나만 활성화(1 또는 High)시킵니다.
명령어 해독: CPU가 메모리에서 가져온 기계어(0과 1의 조합)가 '덧셈'인지 '뺄셈'인지 분석하여 ALU에 신호를 보냅니다.
주소 지정: 메모리(RAM)에서 특정 데이터가 저장된 위치(주소)를 찾아내고 선택할 때 사용합니다.

3. 컴퓨터 구조에서의 역할 (ALU와의 연결)
명령어 인출: CPU가 메모리에서 명령어 코드(예: 0010)를 가져옵니다.
디코더 해독: 제어 장치 내부의 디코더가 0010을 입력받아 "이 명령은 덧셈이다"라는 것을 알아내고 해당 제어 선을 켭니다.
ALU 실행: 디코더가 켠 제어 신호를 받아 ALU가 실제 산술 연산(덧셈)을 수행합니다.
