# Decorder
>디코더(Decoder, 복호화기)는 컴퓨터가 이해하는 이진수나 암호화된 데이터를 사람이 읽을 수 있는 언어나 특정 제어 신호로 변환하는 장치 또는 알고리즘입니다. 

### ⚙️ 1. 디지털 전자회로 (컴퓨터 구조)
>컴퓨터 하드웨어에서 디코더는 $$n$$ 개의 입력 신호를 받아 최대 $$n^2$$ 개의 출력 신호 중 하나를 선택하는 조합 논리회로입니다. 
- 명령어 해독
    >CPU가 메모리에서 가져온 명령어(OP 코드)를 분석하여 알맞은 연산 장치를 작동시킵니다.
- 주소 지정 
    >메모리의 특정 주소(이진수 데이터)를 활성화하여 데이터를 읽거나 씁니다. 
### 🧠 2. 인공지능 및 딥러닝 (AI)
>Transformer, 딥러닝 인코더-디코더 모델(예: LLM, 번역기)에서 사용되는 핵심 모듈입니다. 
- 출력 데이터 생성
    >인코더가 압축한 추상적인 데이터(벡터 값)를 바탕으로 사람이 이해할 수 있는 텍스트, 이미지, 음성 등의 최종 결과물을 만들어냅니다.
- 적용 사례
    >챗봇의 답변 생성, 파파고 등의 기계 번역, 이미지 캡셔닝 시스템. 

### 🎬 3. 멀티미디어 및 소프트웨어
> 데이터 전송 속도를 높이거나 용량을 줄이기 위해 압축된 비디오, 오디오 파일을 화면과 스피커로 출력해 주는 프로그램입니다.
- 코덱(Codec)
    >데이터를 압축하는 인코더(Encoder)와 압축을 푸는 디코더(Decoder)의 합성어입니다.
- 적용 사례
    >동영상 플레이어(H.264, HEVC 디코더), 오디오 플레이어(MP3, AAC 디코더), 웹사이트 데이터 변환(Base64 디코더).
