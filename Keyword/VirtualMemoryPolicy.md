# 가상메모리 관리정책
>가상메모리 관리정책은 한정된 물리 메모리(RAM)를 효율적으로 사용하여 시스템 성능을 극대화하기 위한 CPU와 운영체제의 행동 규칙입니다. 이 정책은 데이터를 언제(가져오고), 어디에(배치하고), 무엇을(내보낼지)에 따라 크게 3가지로 분류됩니다.

### 가져오기 정책 (Fetch Policy)
>보조기억장치(SSD/HDD)에 있는 프로세스의 데이터를 언제 물리 메모리로 가져올지 결정하는 정책입니다.

- 요구 페이징 (Demand Paging): 
    >CPU가 실행 중 특정 페이지를 요구(참조)할 때만 해당 페이지를 메모리에 적재합니다. 대부분의 현대 운영체제가 채택하고 있으며 메모리 낭비를 줄입니다.선페
- 선페이징 (Prepaging): 
    >공간 지역성을 바탕으로, 참조될 가능성이 높은 페이지를 미리 예측하여 한꺼번에 메모리에 적재합니다. 초기 기동 시 페이지 부재(Page Fault)를 줄일 수 있지만, 예측이 틀리면 메모리가 낭비됩니다.

### 배치 정책 (Placement Policy)
>디스크에서 가져온 페이지나 세그먼트를 물리 메모리의 어느 위치에 저장할지 결정하는 정책입니다. (주로 가변 크기를 다루는 세그먼테이션 구조에서 중요합니다.)

- 최초 적합 (First-Fit): 
    >메모리의 처음부터 탐색하여 들어갈 수 있는 가장 첫 번째 빈 공간에 배치합니다. 탐색이 빨라 효율적입니다.
- 최적 적합 (Best-Fit): 
    >메모리 전역을 탐색하여 프로세스 크기와 가장 크기 차이가 적은 빈 공간에 배치합니다. 내부 단편화를 최소화하지만 탐색 시간이 오래 걸립니다.
- 최악 적합 (Worst-Fit): 
    >가장 크기가 가장 큰 빈 공간에 배치합니다. 남는 공간이 커서 다른 프로세스가 들어올 가능성을 남기지만, 빈 공간을 금방 소모합니다.

### 교체 정책 (Replacement Policy)
>물리 메모리가 가득 찼을 때, 새로운 페이지를 할당하기 위해 어떤 기존 페이지를 제거할지 결정하는 정책입니다.

- FIFO (First-In, First-Out): 
    >메모리에 가장 먼저 들어온 페이지를 먼저 내보냅니다.
- LRU (Least Recently Used): 
    >과거 데이터를 바탕으로 가장 오랫동안 사용되지 않은 페이지를 내보냅니다. 성능이 우수하여 가장 널리 쓰입니다.
- LFU (Least Frequently Used): 
    >참조된 횟수가 가장 적은 페이지를 내보냅니다.
- NUR (Not Used Recently): 
    >최근 참조 여부(Reference Bit)와 변형 여부(Modified Bit)를 나타내는 2개의 비트를 두어, 최근에 사용되지 않은 페이지를 빠르게 찾아 교체합니다.

### 할당 및 프레임 관리 정책 (Allocation Policy)
>각 프로세스에 물리 메모리 공간(프레임)을 얼마나 나누어 줄지 결정하여 스래싱(Thrashing)을 방지하는 정책입니다.

- 고정 할당 (Fixed Allocation): 
    >프로세스 크기에 상관없이 또는 일정 비율로 프레임을 고정해서 할당합니다.
- 가변 할당 (Variable Allocation): 
    >프로세스의 실행 상태와 페이지 부재 빈도에 따라 프레임 수를 유동적으로 조절합니다.
- 워킹 세트 (Working Set) 알고리즘: 
    >프로세스가 일정 시간 동안 자주 참조하는 페이지 집합(Working Set)을 메모리에 항상 유지하여 페이지 부재를 최소화합니다.
